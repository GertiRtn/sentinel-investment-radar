# Frozen holdout protocol

Recorded before holdout data inspection. Evaluate BTCUSDT 28-day and ETHUSDT 14-day momentum independently over 2024-07-01 through 2026-10-31 with June 2024 warm-up. These candidates were chosen during development and both passed the predeclared positive validation return gate. The validation results and subsequent timing and doubled-cost sensitivities were already observed, so the holdout is the only remaining untouched period.

Use official Binance monthly daily spot archives and checksum sidecars. Validate daily continuity and timestamp units. Start each asset independently with 50 USDT cash. Signal uses the last completed close versus its 28/14-day lag. At the next daily open switch between asset and cash, subject to assumed 10 bps fee and 5 bps combined adverse half-spread/slippage per side. Mark open positions at the final close, with no exit charge, consistent with development and validation. Buy-and-hold starts on the first open with the same cost assumptions, cash is the other benchmark. No exchange minimum or quantity filters are modeled.

The main result uses that frozen next-open model. A one-hour execution proxy and doubled-cost run are secondary, descriptive sensitivity checks, not inputs to candidate selection. A one-hour price is still a proxy. Report return, maximum close-to-close drawdown, number of fills, time exposed and fees, along with hold benchmarks and the limitations. Preserve the exact input hashes, code hash, protocol hash and outputs. No reruns with altered rules presented as the untouched experiment. Errors that invalidate data or calculations require an explicit correction record and a fresh review, not silent replacement. No live orders or credentials.
